# ui — интерфейс аналитика

Веб-интерфейс на Streamlit поверх `worker`: проверка объекта, просмотр находок с уликами, база знаний, кампании,
пакет правил и метрики. Дополняет CLI и REST API (ТЗ не требует графического интерфейса).

## Архитектура

```
аналитик ─► :8501 app.py (Streamlit) ─► backend.py ─► REST API worker :8000
                       └─ render.py (улики: HTML, URL, цепочка редиректов, область логотипа на снимке)
```

### Ключевые компоненты

**`app.py`** — страницы и навигация.
**`backend.py`** — обращения к `worker` по REST (или напрямую к его модулям при локальном запуске).
**`render.py`** — отображение находок: каждая с объяснением и уликой, сформированное правило человеческим языком.

## Быстрый старт

### Требования

- Python 3.10+ и зависимости `requirements.txt`; запущенный `worker` (или локальный запуск из корня репозитория).

### Конфигурация

| Переменная | Обязательная | По умолчанию | Описание |
|---|---|---|---|
| `WORKER_HOST` | нет | `localhost` (в Docker — `worker`) | адрес `worker` |
| `WORKER_PORT` | нет | `8000` | порт `worker` |

### Запуск

```bash
docker compose up -d ui                         # http://localhost:8501
python -m streamlit run services/ui/app.py      # локально, из корня репозитория
```

### Остановка

```bash
docker compose stop ui
```

## Страницы

| Страница | Что показывает |
|---|---|
| Проверка объекта | образец датасета, файл, сохранённая страница или URL → вердикт, находки с уликами, правило, YARA, отпечатки, работа агентов; кнопки «Скачать результат (JSON)» и «Скачать YARA» |
| База знаний | частота техник, таблица объектов с фильтрами |
| Кампании | объекты с общим kit / инфраструктурой |
| Пакет правил | версия пакета, вклад правил, происхождение, сигнатуры; скачивание YARA и ZIP |
| Метрики | критерии приёмки по тестовому набору EML, корпусу Заказчика и устойчивости |
